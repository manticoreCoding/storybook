# KAN-19: Add storybooks to favourites

## Intent
Allows children and parents to add storybooks to their favourites using a flag icon so they can reach preferred stories faster.

## Acceptance criteria
- A flag icon is available to the user in the top-right corner of each story card in the story list.
- Clicking the flag icon adds the story to favourites and places it at the top of the user story list.
- Clicking the flag icon again removes the story from favourites.
- Favourites are saved per signed-in user and persist across device changes and sign out and sign in cycles.
- The story list displays favourites first, followed by all other stories, while maintaining the existing order within each group.

## Out of scope
- Any new designs for favorites other than the flag icon.
- Changes to the existing order of stories within their respective groups.
